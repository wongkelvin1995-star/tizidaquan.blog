**直接结论**：规范使用正规来源的机场与代理客户端，在现代 **HTTPS (TLS 1.3)** 端到端加密的保护下，日常网页浏览、AI 对话与海外流媒体访问是相对可控且安全的；但**不存在任何“绝对安全、绝对匿名”的代理服务**。真正需要防范的安全风险主要来自三处：**下载到被植入木马的假冒客户端**、**在非 HTTPS 明文网站提交敏感数据**，以及**在代理后台与重要个人网站之间共用同一套账号密码**。

## 一、从技术链路看清“谁能看见什么”

| 链路环节 | 本地网络 / 运营商 | 机场服务端（入口与落地） | 目标网站（如 GitHub / OpenAI） |
|---|---|---|---|
| **您本地电脑 IP** | 可见 | **可见**（入口服务器可看到连接来源 IP） | 仅看到机场落地节点的出口 IP |
| **访问了哪个域名** | 被加密隧道隐藏（看不到具体海外域名） | **可见**（通过 DNS 查询与 TLS SNI 识别） | 可见 |
| **具体提交的密码、正文内容** | 不可见 | 若目标网站启用 **HTTPS**：**不可见**；若访问老旧 HTTP 明文站：**可见** | 可见 |

## 二、客户端安全比“节点宣传”更重要

1. **客户端运行在您的本机操作系统**：一旦不小心安装了从网盘或高仿中文站下载的“加料客户端”，它拥有本机权限，不仅能窃取剪贴板、浏览器保存的密码和钱包密钥，甚至能绕过 HTTPS 注入自定义根证书监听明文内容。
2. **严禁接受来源不明的“安装自定义根证书”请求**：正规科学上网代理（无论官方客户端还是 Clash/Shadowrocket）**不需要**您在电脑或手机系统里安装第三方根证书来进行解密抓包。遇到任何非官方教程诱导安装系统级 CA 证书的，立刻停止操作！

## 三、日常安全使用四项底线

- **只在官网用户中心或官方开源 GitHub Release 下载软件**，切勿关闭系统自带防病毒与防火墙核心防护。
- **不在没有 HTTPS 锁标的陌生网页输入账号密码或支付卡号**。
- **使用独立邮箱和独立高强度密码注册机场**，详见 [机场隐私保护怎么做](/safety/privacy/)。
- **保护好您的订阅链接与官方端登录凭证**，切勿在公开求助帖中贴出含 Token 的订阅 URL。
