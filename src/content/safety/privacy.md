**直接结论**：保护个人隐私不能靠寄希望于服务商“良心”，而要靠自己建立**本地隔离防线**。通过执行 **“独立邮箱 + 独立密码 + 绝不泄露订阅 Token + 善用分应用代理与无痕隔离”** 这套完全由您掌控的操作规范，即便在多设备日常高频使用机场的情况下，也能大幅降低账户关联与信息暴露风险。

## 一、账户与支付层隐私保护清单

1. **一户一密 + 密码管理器**：注册机场时利用系统或开源密码管理器生成 16 位以上随机密码，绝不复用到个人重要账号。
2. **邮箱隔离**：准备一个专用于注册海外软件和工具的独立常规邮箱，既能顺利接收验证码与公告，又避免把您的工作单位邮箱或实名手机号直接暴露给第三方站点。
3. **购买凭证与截图脱敏**：在社交平台咨询问题或联系客服时，提交的截图务必遮盖或裁剪掉完整的个人邮箱、订单流水号以及包含 Token 的订阅链接。

## 二、客户端与连接层防护措施

- **坚决不把真实订阅 URL 上传到未知网站**：任何要求您把订阅链接贴进网页框里“帮您测速/帮您转 Clash 格式/帮您体检节点”的陌生工具站，都可能瞬间复制保存您的订阅密钥。
- **安卓手机善用“分应用代理”**：在支持的 Android 工具中将本地网银、政务服务及支付软件设为绕过代理（直连），减少本地敏感业务经过不必要中间路由的概率。
- **排查 IPv6 与 DNS 泄漏**：确保系统不会在开启代理的同时由本地宽带 IPv6 直接泄露请求或走本地明文 ISP DNS 解析海外域名。

## 三、浏览器与设备侧日常习惯

- **区分浏览器工作配置文件**：在 Chrome 或 Edge 中将“国内日常办公登录配置”与“海外工具检索配置”拆成两个独立的 Browser Profile，避免海量国内站点 Cookie 与海外账号环境混杂。
- **使用正版系统与定期清理缓存**：切勿在已感染流氓软件或长期未打补丁的盗版系统（如早已停服的 Windows 7）上登录重要个人云盘与开发后台。
