**直接结论**：如果您的机场支持第三方客户端（如 Clash 或 Shadowrocket），订阅链接通常位于官网登录后的 **首页仪表盘（Dashboard）顶部或中部“一键订阅 / 复制订阅地址”按钮**内；**绝对不是浏览器地址栏里的网站首页网址**。如果后台完全没有订阅按钮，则说明该品牌目前采用的是“**封闭官方客户端账号登录模式**”，直接下载官网客户端登录即可。

## 一、先确认：您用的品牌究竟有没有订阅链接？

在 18 家品牌资料中，对订阅链接的策略分为明确的三类（以下依据历史公开档案）：

1. **支持导入第三方客户端**：例如 [飞猫云](/brands/feimaoyun/) 明确标明支持导入 Clash、小火箭等第三方客户端。
2. **高阶档位可申请或不同资料口径需询问客服**：例如 [灵动云](/brands/lingdongyun/) 标注符合条件的高流量套餐用户可联系官方客服申请订阅；[跨界](/brands/kuajie/)、[闪跃](/brands/flashleap/)、[唯兔云](/brands/v2yun/)、[无忧链接](/brands/wuyou/) 在不同历史资料中表述存在差异，需在后台查看或咨询在线客服。
3. **不提供订阅链接（仅限官方客户端）**：[微风网络](/brands/breezenet/)（2026-10起新订单）、[隐形人](/brands/yinxingren/)、[FLYV](/brands/flyv/)、[Firefly](/brands/firefly/)、[Sogo云](/brands/sogoyun/)、[浪网](/brands/wavenet/) 等，不对外发放订阅链接，直接安装官方 App 登录使用即可。

## 二、如何正确找到并完整复制订阅链接？

对于明确提供订阅链接的面板（通常为 SSPanel 或 V2Board 风格后台）：

1. 登录品牌官网后，停留在 **仪表盘（首页）** 或进入 **我的订阅 / 节点配置** 页面。
2. 点击页面上的 **“一键导入”** 旁边的小按钮：**“复制订阅链接” / “Copy Subscription URL”**（注意不要自己用鼠标拖选屏幕上的截断文字，因为长 Token 常带有隐藏字符，拖选极易漏掉首尾字母）。
3. 如果面板区分 **“Clash 订阅”** 与 **“通用订阅 / V2Ray / Shadowrocket 订阅”**：
   - 使用 Clash Verge Rev / Mihomo / OpenClash 时复制专用或通用转换订阅链接；
   - 使用 Shadowrocket / v2rayNG 时复制通用 Base64 订阅链接（多数现代机场面板也支持自动识别客户端 User-Agent 下发对应格式）。

## 三、复制与粘贴时的常见错误及安全铁律

| 常见错误 | 导致的故障现象 | 正确避坑方法 |
|---|---|---|
| **直接复制浏览器地址栏网址** | 导入报错 YAML invalid 或解析节点为 0 | 必须点后台专门的“复制订阅”按钮，获取以 `/api/v1/client/subscribe?token=...` 或类似格式结尾的链接 |
| **微信/QQ 转发链接被二次转义或截断** | 跨设备发给自己时 `&` 或 Token 被屏蔽 | 使用安全本地剪贴板同步或备忘录加密传送，勿发在公开群聊 |
| **将真实订阅链接发到论坛或未知在线转换器** | 流量莫名瞬间耗尽，出现异地并发封号 | **绝不向任何不明第三方在线订阅转换网站粘贴真实订阅**；如怀疑已泄露，立刻在后台点击“重置订阅链接”使旧链接作废 |
