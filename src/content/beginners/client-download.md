**直接结论**：获取机场客户端只有两条合规安全通道——**① 购买品牌的官方自研客户端，只允许登录品牌官网“用户中心 > 客户端下载”获取**；**② 开源第三方客户端（如 Clash Verge Rev、Mihomo Party、Clash Meta for Android），只允许从对应的官方 GitHub 组织 Releases 页面下载，并在 iOS 端仅通过海外区 App Store 官方商店购入 Shadowrocket 等正版应用**。

## 一、绝不碰触的四大高危假冒下载渠道

| 高危来源 | 常见伪装套路 | 潜在风险 |
|---|---|---|
| **搜索引擎带“广告/推广”字样下载站** | 域名常叫 `clash-cn.com`、`shadowrocket-free.net` 等高仿中文站 | 下载下来往往是捆绑广告软件、流氓导航甚至远控木马的 EXE 安装器 |
| **网盘共享压缩包（附带解压密码）** | 贴吧/小红书/视频评论区留网盘链接并写“关闭杀毒后运行” | 专门用来绕过系统静态查杀的典型木马传播手法 |
| **iOS“免越狱免费企业签名描述文件”** | 宣称无需外区账号即可免费安装小火箭 | 随时可能掉签闪退，且部分恶意描述文件会监控甚至锁定手机 |
| **陌生群私发或闲鱼售卖客户端包** | 号称“内置永久免费节点版” | 高概率夹带后门或引流欺诈 |

## 二、Windows / macOS / Android 核对文件完整性的简单方法

下载开源客户端（如在 GitHub Release 下载后）时，如果发布页附带了 `SHA256` 校验文件（如 `.sha256.txt`），只需 5 秒钟就能验明文件未被中途篡改：

- **Windows PowerShell**：`Get-FileHash .安装包文件名.exe -Algorithm SHA256`
- **macOS / Linux 终端**：`shasum -a 256 安装包文件名.dmg`（或 `sha256sum`）

将算出来的 64 位十六进制字符串与 GitHub 发布页面上作者公布的对比，一字不差即代表是原汁原味的正版编译包。

## 三、如果已经打不开机场官网，怎么安全找回最新下载入口？

不要用搜索引擎瞎搜“XX机场最新下载”，而应查看您注册时保存的**官网防失联页、官方邮件通知或官方公告频道**，详情参见 [机场官网真假识别](/safety/website-verification/) 与 [机场打不开怎么办](/troubleshooting/website-unavailable/)。
